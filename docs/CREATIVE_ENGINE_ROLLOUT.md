# Creative engine rollout ledger

This enhances the existing engines. Catalog membership does not mean execution,
license approval, RTL certification, or a measured performance result.

## Completed increments

- `66f11ce`: shared read-only registry, native per-segment effects and boundary
  transitions in Studio Edit, unified controls and derived timeline tracks.
- `27578a6`: deterministic resource eligibility used by native EditPlan
  resolution; explicit context/engine/type checks, unknown required capabilities
  rejected, no agent-mode or engine switching. 41 focused tests passed.
- Local source fingerprints: six committed metadata/adapter files exposed in
  registry summary; missing or changed files report an integrity failure.
  Fingerprints are **not** upstream installation pins or license receipts.
- Director talking_2 beats now receive bounded, source-anchored local recipe
  choices. Choices survive plan serialization and compiler binding; the native
  builder revalidates IDs and preserves semantic visual types instead of
  rotating repeated steps into unrelated charts. Other styles are unchanged.
  External catalog execution and product recipe ports remain separate gates.
- Native HyperFrames QC separates style advisories from measured defects and
  unavailable inspection. Real FFmpeg fixture tests confirm intentional static
  black scenes pass, truncated output fails, and inspection timeouts do not
  become fictional visual defects. Automatic semantic template rotation is
  disabled. This is not full audio/visual certification or model QA replacement.
- The two existing external adapters now install only from HyperFrames commit
  `07b0f2cda1cf7b51e0f12d0d05c304b37b4e881c`, checking fixed SHA-256 values
  before writing any code. An Apache-2.0 license copy and per-resource source
  receipt accompany each install. Real temporary-directory installs passed for
  both files. Fonts/runtime/assets remain independently unapproved; this does
  not certify rendering or approve the other catalog entries.

## Remaining acceptance gates (not completed)

1. Upstream immutable install receipts and per-item code/assets/fonts license
   evidence. The current HyperFrames CLI installation can fetch mutable upstream
   content; local fingerprints do not solve that.
2. Source-grounded visual beat/resource selection integrated with Director and
   explicit approval; bounded discovery, no invented executable IDs.
3. Real project previews, not CSS schematic samples; cancellation and caching.
4. Build-probed FFmpeg xfade adapter, separate from current MLT transitions.
5. Selected licensed HyperFrames/HTML ports and the three Python VFX pilots
   (orbit, backdrop-word, locked-on), with shared analysis caches.
6. Persian mixed-script/alpha/seek certification per adapter; actual renders.
7. Evidence-based visual/audio QA and bounded targeted repair, without treating
   intentional black outros or unavailable model services as visual defects.
8. Partial-render invalidation and measured 10/30/60-second CPU/RAM/AV-sync
   benchmarks on local and server hardware.

No production deployment, paid generation, blanket commercial approval, or
hardware-specific iOS verification is implied by this ledger.
